# recipes.willjackson uk (aka Approved by Georgie)

A simple Astro blog containing a collection of recipes tested and approved by Georgie. Based on the [Astro Starter Kit: Blog](https://github.com/pedes/astrojs-blog-starter-website).

## Description

This is a personal recipe collection that Georgie and I have built up over time, where every dish has been personally tested and approved by me and, more importantly, Georgie.

Georgie has some strong opinions when it comes to food: specifically that it should be interesting but not _too_ interesting. Spice should be used cautiously, if at all. Under no circumstances should a recipe ever include an olive.

I found myself constantly adjusting recipes I found on the Internet to meet these requirements, making notes as I went in a slightly singed, gravy-stained notebook kept by the hob. I was learning web design at the time, so I eventually decided to upgrade that notebook to a proper blog. As the list grew, I also added a tag feature, allowing us to pick a general mood and be presented with a curated list of options for that night's dinner.

As the list got longer, I decided to add a tag feature. That way we could pick the sort of thing we were in the mood for and be presented with a list of options. Usually this involves eggs, for some reason. 

It’s nothing fancy at the moment, but I’m playing the long game. With a few cringe-inducing reaction photos and some generous bulking out with stories from my childhood and visits to the Isle of Wight, I could someday achieve the dream of becoming a minor food influencer. It’s a niche market, but someone has to dominate the world of moderately interesting, olive-free, predominantly egg-based dining. I'm expecting an offer for a column in The Telegraph any day now.

## Project structure

Astro will look for `.mdx` files inside the `src/content/recipes/`. If the file is valid, it will be added to the recipe blog under its file name. 

`src/content/` also contains a `blog` folder. This is left over from the original Astro blog template and not currently used, but has been kept just in case I decide to use it in the future. 

Recipe posts use the layout located at `src/layouts/RecipePost.astro`. This layout is very simple, but includes the option for an image to be included if necessary. I've disabled these as I can't seem to be able to take a decent food photo.  

I built the tag feature myself to help me and Georgie navigate the recipes. The tag pages and listings are generated by the files inside `src/pages/tags`. I might expand on this in the future, but it seems to do the job for now.

Each recipe `.mdx` file requires the following frontmatter:

```
---
title: Recipe Title
pubDate: 'YYYY-MM-DD'
tags: ['tag1', 'tag2']
draft: false
description: A short description of the recipe.
---
```

Setting `draft: true` hides a recipe from the site without deleting it. Tags are used to generate the tag pages and can be any string; new tags are picked up automatically.

An RSS feed is generated automatically at `/rss.xml` by `src/pages/rss.xml.js`.

Static assets are stored in the `public/` directory.
